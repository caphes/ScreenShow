# ScreenShow

ScreenShow передаёт изображение основного экрана и даёт владельцу выбрать, разрешить ли удалённую мышь и клавиатуру. Приложение работает на Windows 10 и 11 с .NET Framework 4.8 или новее.

[Готовые сборки для Windows и Android](https://github.com/caphes/ScreenShow/releases/latest)

## Подключение

1. Запустите `bin\ScreenShow.exe` на обоих компьютерах. Для второго компьютера достаточно скопировать сам файл.
2. На компьютере, чей экран нужно показать, выберите сетевой адрес. Для одной домашней сети подойдёт адрес Wi-Fi или Ethernet. Для подключения через VPN выберите адрес VPN.
3. Нажмите **Открыть доступ**. Для первой привязки нажмите **Копировать** и передайте приглашение устройству, которое хотите добавить.
4. На втором компьютере нажмите **Вставить** и **Подключиться**. На первом выберите **Только просмотр** или **Разрешить управление**. Запрос ждёт ответа, пока клиент подключён.
5. Если управление разрешено, на втором компьютере нажмите **Включить ввод**. Кнопка **Отключиться** завершает сеанс. На первом компьютере сеанс можно завершить кнопкой **Остановить** или сочетанием **Ctrl+Alt+F12**, когда оно указано в строке состояния.

После первого одобрения связь сохраняется на обоих устройствах. В дальнейшем откройте доступ на ПК и выберите его в **Устройствах** на клиенте. Сеанс запустится с сохранённым разрешением. В разделе **Устройства** на принимающем ПК можно изменить режим или отозвать привязку. У привязок из версии 1.1.0 исходный режим не сохранялся, поэтому после обновления для них действует **Только просмотр**, пока владелец ПК не включит управление. Если IP-адрес или порт ПК изменится, отправьте новое приглашение. Соединение шифруется TLS.

Для прямого подключения используется TCP-порт `47210`, его можно изменить до создания приглашения. Если брандмауэр Windows запрашивает доступ, разрешите ScreenShow входящие подключения для нужной сети. Устройства должны видеть друг друга по выбранному адресу через локальную сеть или общий VPN.

Для проверки на одном компьютере запустите два экземпляра, выберите **127.0.0.1 · Этот компьютер** и подтвердите **Только просмотр**. В окне просмотра появится изображение этого же экрана, включая само окно просмотра.

## Подключение с Android

1. Скопируйте `bin\ScreenShow-Android.apk` на телефон с Android 8.0 или новее и установите его.
2. Подключите телефон и ПК к одной локальной сети или общему VPN. На ПК запустите `bin\ScreenShow.exe`, выберите соответствующий сетевой адрес и нажмите **Открыть доступ**.
3. В приложении на телефоне вставьте приглашение и нажмите **Подключиться**. При первой привязке выберите разрешение на ПК.
4. Для управления нажмите **Включить ввод**. Касание соответствует левому клику, удержание — правому, движение одним пальцем — перетаскиванию. При обычном масштабе движение двумя пальцами прокручивает содержимое на ПК. В меню **Клавиши** можно нажать отдельную клавишу или отправить текст, в том числе на русском.
5. Для следующего подключения выберите ПК в списке **Связанные компьютеры**. Сеанс откроется автоматически, пока на ПК открыт доступ. Чтобы удалить сохранённый адрес с телефона, нажмите **Забыть**. Чтобы отозвать доступ, нажмите **Отвязать** на ПК.

Для отправки текста используйте Windows-версию из той же папки `bin`. Поворот телефона в альбомную ориентацию увеличивает полезную площадь для просмотра рабочего стола.

## Подключение через интернет

### Напрямую

1. Нужен публичный IPv4 у домашнего подключения или DDNS, указывающий на этот адрес. За роутером направьте входящий TCP-порт на локальный адрес ПК и порт ScreenShow. Например, внешний `47210` → `192.168.1.10:47210`. Для стабильности закрепите локальный адрес ПК в DHCP роутера. Разрешите входящие соединения ScreenShow в брандмауэре Windows.
2. На ПК выберите **Интернет напрямую**. В поле **Порт** укажите локальный порт, затем нажмите **Открыть доступ** и введите публичный адрес и внешний порт, например `my-pc.example.net:47210`.
3. Отправьте приглашение `SSI-…` на телефон. Отключите Wi-Fi на телефоне, вставьте код в ScreenShow и подтвердите первую привязку на ПК. При повторном подключении используйте сохранённый компьютер. DDNS удобен, если публичный IP периодически меняется.

При CGNAT переадресации только на домашнем роутере обычно недостаточно. Уточните у провайдера возможность входящих подключений или получения публичного IPv4.

### Через сервер-посредник

Устройства в разных сетях могут подключиться через ваш сервер-посредник. Например, Windows может быть дома, а Android — в мобильной сети. Оба устройства устанавливают исходящее TCP-соединение с сервером, поэтому на домашнем роутере пробрасывать порт не нужно.

1. На VPS или другом компьютере, доступном из интернета, запустите `node relay/server.js`. У сервера нет сторонних пакетов. Разрешите входящие TCP-соединения на порту `47211` на сервере. Для другого порта задайте переменную окружения `SCREENSHOW_RELAY_PORT`.
2. В ScreenShow на ПК выберите **Интернет через сервер**, нажмите **Открыть доступ** и введите публичное имя или IPv4-адрес сервера с портом, например `relay.example.org:47211`.
3. Скопируйте приглашение `SSR-…` и вставьте его в актуальной версии ScreenShow на другом ПК или на Android. После первой привязки эту запись можно открывать из списка связанных устройств.

Сервер принимает обычное TCP-соединение. Если сервер находится за прокси, нужен режим пересылки TCP. ScreenShow проверяет отпечаток сертификата ПК из приглашения и шифрует видео и ввод внутри соединения. Сервер только пересылает зашифрованные данные.

## Автозапуск Windows

Откройте доступ и включите **Открывать доступ при входе в Windows**. ScreenShow запускается для текущего пользователя после входа в рабочий стол и использует последнее сохранённое подключение. Разместите `ScreenShow.exe` в постоянной папке, чтобы Windows могла найти его при следующем входе.

В области уведомлений есть значок ScreenShow с состоянием и командой **Остановить доступ**. Во время трансляции открывается окно с индикатором сеанса. Новое устройство проходит первый запрос разрешения. Для связанных устройств используются сохранённые права.

## Масштаб экрана

- На Android разведите два пальца, чтобы приблизить экран. Перемещайте увеличенное изображение двумя пальцами. В режиме просмотра можно перемещать его одним пальцем.
- На Windows используйте **+**, **−** или **Ctrl+колесо мыши**. Перетаскивайте увеличенное изображение мышью. При активном удалённом вводе для перемещения изображения удерживайте **Shift**.
- Текущий масштаб отображается на панели сеанса. Кнопка **По размеру** снова показывает весь экран.

## Сборка и проверка

- `Build.cmd` собирает `bin\ScreenShow.exe` стандартным компилятором .NET Framework на 64-разрядной Windows.
- `tests\Run.cmd` проверяет приглашение, TLS, получение кадра, сохранение и отзыв привязки через `127.0.0.1`. Параметр `--long` проверяет подтверждение спустя более 30 секунд. Запускайте тест из обычного сеанса Windows с доступом к рабочему столу и хранилищу ключей текущего пользователя.
- `android\Build.cmd` собирает и подписывает APK. Для сборки нужны JDK, Android SDK Platform 36 и Build Tools 36.0.0. Укажите `JAVA_HOME` и `ANDROID_HOME` или используйте локальный SDK в `android\.sdk`. Ключ локальной подписи хранится в `android\.signing`. Сохраняйте его для установки обновлений поверх предыдущей сборки.
- `android\tests\Run.cmd` проверяет соединение Java-клиента с Windows, проверку сертификата, формат кадров, передачу кириллицы и подключение обоих клиентов через временный сервер-посредник. Для теста требуются JDK и Node.js.
