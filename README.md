# ScreenShow

ScreenShow передаёт изображение основного экрана и даёт владельцу выбрать, разрешить ли удалённую мышь и клавиатуру. Приложение работает на Windows 10 и 11 с .NET Framework 4.8 или новее.

[Готовые сборки для Windows и Android](https://github.com/caphes/ScreenShow/releases/latest)

## Подключение

1. Запустите `bin\ScreenShow.exe` на обоих компьютерах. Для второго компьютера достаточно скопировать сам файл.
2. На компьютере, чей экран нужно показать, выберите сетевой адрес. Для одной домашней сети подойдёт адрес Wi-Fi или Ethernet. Для подключения через VPN выберите адрес VPN.
3. Нажмите **Создать приглашение**, затем **Копировать**. Передайте код человеку, которого хотите подключить.
4. На втором компьютере нажмите **Вставить** и **Подключиться**. На первом компьютере в течение 30 секунд выберите **Только просмотр** или **Разрешить управление**.
5. Если управление разрешено, на втором компьютере нажмите **Включить ввод**. Кнопка **Отключиться** завершает сеанс. На первом компьютере сеанс можно завершить кнопкой **Остановить** или сочетанием **Ctrl+Alt+F12**, когда оно указано в строке состояния.

Приглашение действует на одну попытку с правильным кодом. Соединение шифруется TLS. Адрес и отпечаток временного сертификата передаются в приглашении.

По умолчанию используется TCP-порт `47210`, его можно изменить до создания приглашения. Если брандмауэр Windows запрашивает доступ, разрешите ScreenShow входящие подключения для нужной сети. Оба компьютера должны видеть друг друга по выбранному адресу. Для компьютеров в разных сетях используйте общий VPN. Приложение работает напрямую и обходится без сервера-посредника.

Для проверки на одном компьютере запустите два экземпляра, выберите **127.0.0.1 · Этот компьютер** и подтвердите **Только просмотр**. В окне просмотра появится изображение этого же экрана, включая само окно просмотра.

## Подключение с Android

1. Скопируйте `bin\ScreenShow-Android.apk` на телефон с Android 8.0 или новее и установите его.
2. Подключите телефон и ПК к одной локальной сети или общему VPN. На ПК запустите `bin\ScreenShow.exe`, выберите соответствующий сетевой адрес и создайте приглашение.
3. В приложении на телефоне вставьте приглашение и нажмите **Подключиться**. Подтвердите сеанс на ПК.
4. Для управления нажмите **Включить ввод**. Касание соответствует левому клику, удержание — правому, движение одним пальцем — перетаскиванию, движение двумя — прокрутке. В меню **Клавиши** можно нажать отдельную клавишу или отправить текст, в том числе на русском.

Для отправки текста используйте Windows-версию из той же папки `bin`. Поворот телефона в альбомную ориентацию увеличивает полезную площадь для просмотра рабочего стола.

## Сборка и проверка

- `Build.cmd` собирает `bin\ScreenShow.exe` стандартным компилятором .NET Framework на 64-разрядной Windows.
- `tests\Run.cmd` проверяет приглашение, TLS, решения о доступе, получение кадра и завершение сеанса через `127.0.0.1`. Запускайте тест из обычного сеанса Windows с доступом к рабочему столу и хранилищу ключей текущего пользователя.
- `android\Build.cmd` собирает и подписывает APK. Для сборки нужны JDK, Android SDK Platform 36 и Build Tools 36.0.0. Укажите `JAVA_HOME` и `ANDROID_HOME` или используйте локальный SDK в `android\.sdk`. Ключ локальной подписи хранится в `android\.signing`. Сохраняйте его для установки обновлений поверх предыдущей сборки.
- `android\tests\Run.cmd` проверяет соединение Java-клиента с Windows, проверку сертификата, формат кадров, передачу кириллицы и совместимость с предыдущей Windows-версией.
